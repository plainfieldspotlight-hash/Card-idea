# Repository guide

This repo holds two unrelated projects:

- Root: `pokeprice`, a Python Pokemon card price tracker (see README.md, `src/pokeprice`, `tests/`). CI runs `pytest`.
- `idea-loop/`: Idea Loop, a Next.js + Prisma microlearning app. Read `idea-loop/CLAUDE.md` and `idea-loop/SPEC.md` before working on it. Run its commands from inside `idea-loop/`.
